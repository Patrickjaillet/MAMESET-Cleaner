# MAMESET Cleaner

MAMESET Cleaner est un logiciel de bureau pour Windows qui aide à nettoyer et organiser un set de ROMs MAME : suppression des doublons (clones/parents), filtrage par genre, langue, région, statut de fonctionnement, fabricant et année, pour obtenir un set de ROMs propre, cohérent et minimal (1 jeu = 1 ROM).

> Le projet est en cours de développement (version actuelle : v0.1.0). Les captures d'écran seront ajoutées dès que l'interface sera fonctionnelle.

## Fonctionnalités prévues
- Détection et suppression des doublons de ROMs
- Filtrage par genre, langue, région, statut, fabricant et année
- Utilisation des fichiers de référence officiels MAME (DAT, catver.ini, languages.ini)
- Interface en français et en anglais, thème clair et sombre
- Rapports détaillés des opérations effectuées

## Installation
Un installateur Windows sera fourni à partir de la version v1.0.0.
