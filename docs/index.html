Présentation

MAMESET Cleaner est un logiciel de bureau pour Windows qui aide à nettoyer et organiser un set de ROMs MAME. Il détecte et supprime les doublons (clones/parents) selon la logique 1G1R (1 jeu = 1 ROM), filtre par genre, langue, région, statut de fonctionnement, fabricant et année, et s'appuie sur les fichiers de référence officiels MAME (DAT, catver.ini, languages.ini) pour un résultat fiable.

Fonctionnalités

Scan intelligent

Analyse le dossier de ROMs (.zip, .7z, dossiers non compressés) et détecte les fichiers corrects, manquants, corrompus ou non référencés.

Détection des doublons

Choisit automatiquement le meilleur exemplaire de chaque jeu selon une priorité régionale personnalisable et l'état de fonctionnement.

Filtres avancés

Genre, langue, région, statut, fabricant, année, BIOS, mécanique, contenu adulte : combinez librement vos critères.

Nettoyage sécurisé

Corbeille Windows par défaut, sauvegarde préalable optionnelle et confirmation obligatoire avant toute suppression.

Rapports détaillés

Chaque nettoyage génère un rapport JSON et CSV listant les ROMs supprimées et conservées, avec leur motif.

Interface claire

Français et anglais, thème clair ou sombre, entièrement conçue en Rust natif pour rester rapide sur de très gros sets.
