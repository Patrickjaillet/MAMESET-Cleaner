Overview

MAMESET Cleaner is a Windows desktop application that helps clean and organize a MAME ROM set — and, through plugins, 87 other console systems. It detects and removes duplicates using precise 1G1R logic (1 game = 1 ROM) with a fully configurable region and language priority, filters by genre, language, region, working status, manufacturer and year, and relies on official reference files (DAT, catver.ini, languages.ini) for a reliable result.

Features

Smart scan

Analyzes the ROM folder (.zip, .7z, uncompressed folders) and detects files that are correct, missing, corrupted, or unreferenced. The reference database is cached, so repeat scans skip re-parsing large DAT files and finish dramatically faster.

Precise 1G1R

Works correctly across all 87 systems, not just MAME. Fully reorderable region priority, a language tie-breaker, and official releases always preferred over prototypes and betas. Multi-disc releases are never merged.

Advanced filters

Genre, language, region, status, manufacturer, year, BIOS, mechanical, adult content: pick from real values found in your set, save your favorite combinations as profiles, and reuse them anytime.

Safe cleanup

Windows Recycle Bin by default, optional backup beforehand, and mandatory confirmation before any deletion.

Detailed reports

Every cleanup generates a JSON and CSV report listing deleted and kept ROMs, with their reason. An optional deep-verification mode recomputes SHA1, not just CRC32 and size.

Clean interface

French and English, a polished single theme with real motion and elevation, built entirely in native Rust to stay fast on very large sets.

Multi-console plugins

Beyond its native MAME support, MAMESET Cleaner can install a plugin for another console system directly from its "Plugins" section, which — like the active-system selector in Settings — is grouped by manufacturer with a search box. 87 systems are available today:
